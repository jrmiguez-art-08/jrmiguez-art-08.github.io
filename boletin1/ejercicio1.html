Pasos para Git Commit y Push

  1. Ejecutar git status para verificar los cambios.
  2. Añadir los archivos al área de preparación con git add .
  3. Crear el commit con un mensaje descriptivo: git commit -m "Mensaje"
  4. Subir los cambios al repositorio remoto con git push origin main

Glosario de Términos

HTML
Lenguaje de marcado utilizado para estructurar el contenido de las páginas web.
CSS
Lenguaje de estilos empleado para diseñar y dar formato visual al documento HTML.
DOM
Interfaz de programación (Document Object Model) que representa el documento HTML como un árbol de nodos.
